Lesson 1 AiNova Pro Instruction

1.1.1 Introduction ​

AiNova Pro is an excellent platform for learning AI technology! This robot kit comes with AI vision robot car, multiple sensors, robotic gripper, serial bus servo, mini servo and 100+ LEGO blocks, which can be mixed to build over 16 models.

Various interesting AI games can be achieved through Scratch and Python programming. Its all-in-one solution makes kids enjoy the hands-on experience of programming, electronics, and AI robotics which is excellent to use in classrooms.

1.2.1 Software Introduction ​

WonderCode is the Scratch programming software tool dedicated to Hiwonder products which are powered by CoreX Controller. It supports the automatic conversion of graphical instruction blocks and Python codes, and can be programmed by dragging and dropping blocks. This is easy for novices to learn!

1.2.2 Software Installation ​

  1. Please find the software pack “WonderCode setup.exe” in the folder or in folder “6.
  1. Choose the language and click “Yes”.
  1. Create a desktop shortcut, and click “Next”.

4.When the installation finished, MakeCode shortcut will show on the desk.

1.2.3 Device Connection ​

  1. Connect CoreX Controller to the computer with the USB cable.
  1. Click to open the WonderCode.
  1. Adding the extension pack before connecting the device, other the connection will be fail. Click button to add the extension kit and choose Robot/AiNova.

4.Click “Connect” in the interface and choose the corresponding COM.

Note: The sample port here is COM35, but each computer has a different port. Please choose the port according to your own computer but not the “COM1” which is the system communication port.

5.There will be a pop-up box when connect success.

1.2.4 Programming ​

How to program the LED on the controller to be red through WonderCode software? Please refer to the following steps:

  1. Program after connecting successfully. Find the “AiNova program” in the block bar to drag to the workspace.

    Drag the block back to the toolbar to delete it.

  2. Drag the repeat block to the follow the first one.

  3. Drag the LED block to insert in the Repeat block and set the color as red.

    According to the RGB three-color principle, different threshold combinations of red, green, and blue can synthesize multiple colors. The threshold range is 0-255.

    When the threshold of one of the red, green and blue colors is 255, and the other two colors are 0, the composite result is that color. In the above example, the red threshold is set to 255, and the blue and green thresholds are set to 0.
