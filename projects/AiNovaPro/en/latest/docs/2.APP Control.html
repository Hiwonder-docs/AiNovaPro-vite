2. APP Control ​

2.1 APP Android User Notice ​

APP Android User Notice

The system version requirements: Android 7.0 or above, iOS 9.0 or above.

Choose “Yes” or “Open” for all the pops-up boxes during APP installation.

Please turn on the Bluetooth and GPS service before opening the APP

​

2.2 Getting Ready ​

2.2.1 APP installation ​

Android User：Please send the installation pack in the folder to smart phone to install. Allow all the service for the APP in your phone setting for the operation.

iOS User：Please search “WonderAi” in the APP Store.

Don’t forget to open the GPS location and Wi-Fi service before going to the APP.

2.2.2 Download program ​

  1. Connect AiNova to the computer with USB cable and then turn on WonderCode software. We need to download the program into the controller in advance.

  2. Click “Connect” to choose the corresponding port.

How to find the port number if there are more than one device: Go to the desktop and click “This PC/Properties/Device Manager” to check the port for the AiNova controller which with CH340

  1. Upload the “Bluetooth control” program or drag into the interface directly.
  1. Click in the upper right-hand corner to upload it.

2.2.3 Device Connection ​

  1. Place AiNova on smooth hard surfaces and then turn on switch.

  2. Turn on WonderAi APP to click “AiNova”.

  1. Click the flashing Bluetooth icon in the upper right-hand corner to search the device start with “AiNova-”.
  1. When connect successfully, the Bluetooth icon will stay on and display the battery power.

2.3.2 Line tracking ​

  1. Click in the interface to enter the Line Tracking Mode.

  2. Place AiNova on the map. Click to start the link tracking.

When AiNova cannot follow the line well, please adjust the sensitivity of the line follower. Detailed instruction can be found in the folder 6. Appendix/5. Sensor Adjustment.

2.3.3 Draw to Follow ​

  1. Click to enter the gameplay.

  1. Choose the running pattern for the AiNova to follow. You also can draw the pattern in the interface, and then click to run.

2.4 APP Programming ​

APP Programming

Pleasure make sure that the Bluetooth program was downloaded into the controller and the device connection is successful.

2.4.1 Instruction ​

  1. Choose the “Programming Mode” to start.
InstructionCommand blocks
WorkspaceBuild the blocks to program。
MenuConnect Bluetooth. Read, save and run the programming

2.4.2 Programming ​

Take the writing of a program as an example, in which the RGB color lights turn red and blink.

  1. Click “Logic” part and drag the “Repeat” block to attach the default block on the workspace.

  2. Drag the “Set LED RGB color” in “Display” to attach in the repeat block.

  3. Click the RGB setting block to choose red.

  4. Drag the wait block from “Control” to the RGB block and set the time as 1 second. Drag the turn off block from “Display” box to the last.

  5. Click to run the program for a check

  1. If you want to delete the command, drag the block back to left.

2.4.3 Save and Read the Program ​

  1. Save the program for the later debug and operation. Click and name the file name such as “RGB light”.
  1. Click to read files.
