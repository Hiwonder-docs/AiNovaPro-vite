3.6 Line Following ​

Lesson 6 Line Following

3.6.1 Getting Ready ​

  1. No.5 port on the controller for 4-channal line follower.

  2. Map in the robot kit. Use the black line side for this section.

3.6.2 Learning Objectives ​

  1. Understanding 4-channel line follower sensor and its working principle.

  2. Program AiNova to run following the black line.

3.6.3 Knowledge ​

Program to combine motors with line follower sensor which has four probes and each probe has an infrared transmitter and an infrared receiver.

On a white or other light-colored plane, if the infrared light is reflected, the receiver receives an infrared signal. The blue LED indicator on the line follower will be on. If the infrared light is absorbed or cannot be reflected, the receiver cannot receive infrared signals.

Therefore, we need to set the state of the four probes firstly. Use a judgement block to detect the color to control motors. Then AiNova will move following the black line.

3.7 Distance Reminder ​

Lesson 7 Distance Reminder

3.7.1 Getting Ready ​

Ultrasonic sensor’s connected port (No.4) on the CoreX Controller.

3.7.2 Learning Objectives ​

  1. Understand ultrasonic sensor and programming blocks.

  2. Program AiNova to measure distance and remind.

3.7.3 Knowledge ​

Program to combine glowing ultrasonic sensor with buzzer. When the distance value of the ultrasonic detection is met, RGB will light up and buzzer will play a sound.

There are two probes on the ultrasonic sensor for transmitting and receiving ultrasonic waves. Sending 8 40khz square waves to detect whether there is a signal return automatically. If there is a signal return, it will output a high level voltage. The duration is the time from the ultrasonic emission to the return.

Formula: Tested distance = (high level time * speed of sound (340M/S))/2
