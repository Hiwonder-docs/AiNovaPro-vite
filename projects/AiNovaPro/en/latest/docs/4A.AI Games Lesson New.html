4A.2.2 AI Fan Game Instruction ​

2.3 AI Fan

1. Getting Ready

Please refer to “2.1 AI Fan Assembly Instruction” to assemble AiNova.

2. Learning Objective

  1. Review the distance ranging of the ultrasonic sensor.

  2. Control AiNova to turn on and off the fan via the ultrasonic sensor.

3. Program Logic

In this program, let’s achieve the game via the ultrasonic distance ranging. If an object is detected within a distance of 35cm from the ultrasonic sensor, the fan will be turned on and rotate. Otherwise, it will be turned off.

4. Write Program

  • Select device and load function package

  1. Open the WonderCode.

  2. Click at the lower left corner. Select “AiNova Pro” in the pop-up window.

  3. When AiNova is successfully added as pictured, go back to the home Interface.

  • Combine command block

Download Program

  1. Connect AiNova to computer with the USB cable.

  2. Click “Connect” on WonderCode home interface. Select the corresponding port. Note: There is no fix port. Please select the corresponding port based on actual condition.

    Note: in general, COM1 is system communication interface.

  3. Click after successful connection.

  4. The last step is to wait for it to finish downloading.

Program Outcome

After the program is downloaded, switch the robot on. When the distance between the object and the ultrasonic sensor is less than 35cm, the fan will will be turned on. The ultrasonic sensor's LED will be turned on simultaneously. If the distance exceeds 35cm, the fan and the ultrasonic sensor's LED will be turned off.

Code Analysis

  1. The program initializes the ultrasonic sensor module and servo module. It sets the “servo angle” variable, representing the servo’s rotation angle. The “state” variable is set to represent whether the ultrasonic sensor has detected an obstacle.

  2. The “Update ultrasonic sensor state” function is created. When an obstacle is detected, the “state” is set to 1. Otherwise, it is set to 0.

  3. In the AiNova program, the fan is controlled based on the ultrasonic sensor's “state” value. When “state = 1”, the fan is turned on and rotates. When “state = 0”, the fan stops. The specific analysis is shown below:

  • In the “forever”, the “Update ultrasonic sensor state” function is called to refresh the “state” value of the ultrasonic sensor.
  • If “state = 1”, the obstacle is detected. The ultrasonic sensor's LED and the fan will be turned on. Otherwise, both the ultrasonic sensor and the fan will be turned off.
  • Based on the servo angle value, the fan is made to rotate left and right when it is turned on.
  • If the current angle of the Lego servo is less than 50, the servo value is continuously increased by 3. Until the servo value is greater than 50, indicating the fan leans towards the right. If the ultrasonic sensor's “state” is 0, the servo value stops increment.
  • If the servo value is less than -50, indicating the fan leans towards the left. The servo value will be continuously decreased by 3. The servo spindle will be rotated to control the fan to rotate left and right.

3.3 Speed Variable Car

1. Getting Ready

Please refer to “3.1 Speed Variable Car Assembly Instruction” to assemble AiNova.

2. Learning Objective

  1. Learn how to use the digital tube, knob sensor, and line follower.

  2. Achieve the control of the motor speed via the knob sensor.

3. Program Logic

Adjust the knob sensor to change the voltage level. Assign different speed values and LED colors to different voltage ranges. Then, the digital tube displays the current speed value.

4. Write Program

  • Select device and load function package

  1. Open the WonderCode.

  2. Click at the lower left corner. Select “AiNova Pro” in the pop-up window.

  3. When AiNova is successfully added as pictured, go back to the home Interface.

  • Combine command block

Download Program

  1. Connect AiNova to computer with the USB cable.

  2. Click “Connect” on WonderCode home interface. Select the corresponding port. Note: There is no fix port. Please select the corresponding port based on actual condition.

    Note: in general, COM1 is system communication interface.

  3. Click after successful connection.

  4. The last step is to wait for it to finish downloading.

Program Outcome

After the program is downloaded, switch the car on. Adjust the speed via the knob sensor. Press button A. The car will follow the adjusted speed value to perform line following. The LED will simultaneously emit corresponding lights based on the speed range. Pressing button B will stop the car.

Code Analysis

  1. The motor, ultrasonic sensor, and digital tube are initialized. The values of “stop”, “speed”, and “count” are set to 0.

  2. Use the knob sensor to control the voltage level (AD value). If the AD value is 0, the ultrasonic sensor and LED on the controller will be turned off.

    If the AD value is between 0 and 200, the ultrasonic sensor and the LED will be set to turn green.

    If the AD value is above 200, the ultrasonic sensor and the LED will be set to turn red.

  3. Call the function “Update line follow” to update the detection value of line follower. Call the function “Adjust knob” to set the motor speed. Call the function “Ultrasonic detect” to detect the distance between the ultrasonic sensor and the obstacle. Display the distance on the digital tube. If the “stop” value is 1, which means the distance is less than 35cm, the “count” is set to 0. The car stops.

  • In the function “Update line follow”, four variables “Sensor1”, “Sensor2”, “Sensor3”, and “Sensor4” are set to store the black line value detected by the line follower.

  • In the function “Adjust knob”, three variables are set via the AD value of the knob. The “speed” means motor speed. The “count” and “stop” represent the start and stop flags.

  • In the function “Ultrasonic detect”, the distance between the ultrasonic sensor and the obstacle is displayed on the digital tube. If the distance is less than 35, set “stop” to 1. The car stops line following. The speed can be adjusted by rotating the knob. Otherwise, set “stop” to 0. The car performs the line following.

  • If “stop” is not 1 and the “count” is 1, which means there is an output voltage, the car will start the line following.

  1. In the “Line following” function, control the car to go straight or turn, based on detection outcome of the four probes on the line follower. The “speed” value is determined by the AD value. Different voltage ranges correspond to different speed values. For more details, check the “Adjust knob” function.

6.3 Rampway Reminder Game Instruction

1. Getting Ready

Please refer to “6.1 Rampway Reminder Assembly Instruction” to assemble AiNova.

2. Learning Objective

  1. Master the basic function of the acceleration sensor.

  2. Control the car to detect its own orientation via the acceleration sensor. This allows the car to adjust its speed on the rampway.

3. Program Logic

Use the accelerometer to obtain the car's Euler angles, which represent its tilt angles, and store these values in two variables. Based on the variable values, determine whether the car is going uphill or downhill. If it is going uphill, the vehicle will display a green light; if going downhill, it will light up a red light and activate the buzzer to play a notification sound.

4. Write Program

  1. Open the WonderCode.

  2. Click at the lower left corner. Select “AiNova(Deluxe)” in the pop-up window.

  • Combine command block

Download Program

  1. Connect AiNova to computer with the USB cable.

  2. Click “Connect” on WonderCode home interface. Select the corresponding port. Note: There is no fix port. Please select the corresponding port based on actual condition.

    Note: in general, COM1 is system communication interface.

  3. Click after successful connection.

  4. The last step is to wait for it to finish downloading.

Program Outcome

After the program download is complete, turn on the car's switch. When driving on flat ground, the car will move forward at a constant speed. When going uphill, the car will display a green light; when going downhill, it will light up a red light and activate the buzzer to play a notification sound. The car will maintain a constant speed of 20 while going both uphill and downhill.

Code Analysis

  1. The motor, ultrasonic module, and acceleration sensor are initialized.
  1. The car keeps driving at a speed of 20.
  1. Obtain the Euler angle value via the acceleration sensor. Assign this value to the “angle” variable. If the value of “angle” is greater than 10 degrees, which means the car tilts downward by 10 degrees, the “variable” is incremented by 1.
  1. If the value of “angle” is less than -5 degrees, which means the car tilts upward by 5 degrees, the “variable2” is incremented by 1. If the angle does not change, the buzzer and ultrasonic sensor will not provide feedback. The car will drive at a constant speed of 20.
  1. If the cumulative value of “variable2” is greater than 3, which means the car tilts upward by 15 degrees, the LED and the glowing ultrasonic sensor will turn green.
  1. When the cumulative value of "variable" is greater than 3, which indicates the car tilts downward by 30 degrees, the LED and the glowing ultrasonic sensor will turn red. The buzzer will play a prompt melody. During the process of driving on the rampway, the car keeps a speed of 20.
